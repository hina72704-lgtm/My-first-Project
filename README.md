#  Contact Management System

A professional command-line contact management system built in Python for internship task submission.

##  Features

- ✅ Add new contacts with validation
- ✅ View all contacts in formatted table
- ✅ Search contacts by name, phone, or email
- ✅ Filter contacts by city or company  
- ✅ Update existing contact details
- ✅ Delete contacts with confirmation
- ✅ Automatic save/load to JSON file
- ✅ Unique ID for each contact
- ✅ Case-insensitive search
- ✅ Professional error handling with user guidance

##  How to Run

### Prerequisites
- Python 3.6 or higher

### Steps
1. Download or clone this repository
2. Open terminal in project folder
3. Run the program:
   ```bash
   python main.py
